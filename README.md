# prices — автоматичне заповнення цін у кошторисі СЕС

Скрипт проходить по вкладці **«Довідник обладнання та цін»** робочої Google-таблиці
і проставляє ціни. Для кожної позиції:

| Ситуація | Що робить |
|----------|-----------|
| знайшов у **ETI** | записує ціну (зі знижкою 25 %) — **навіть якщо комірка вже заповнена** |
| не в ETI, але знайшов у **CHINT** | те саме |
| **не знайшов у прайсах**, комірка **заповнена** | лишає як є, в інтернет **не йде** |
| **не знайшов у прайсах**, комірка **порожня** | шукає в інтернеті через Serper |

Тобто заповнена комірка **не захищена** від оновлення: збіг у прайсі постачальника її
перезаписує — у цьому й сенс заміни файлу. Стара ціна не зникає, вона йде в примітку
до комірки: `[Була ціна інженерів: грн.975.00] ETI прайс 1300.00 × 0.75 …`

А от коли збігу в прайсах немає, наявну ціну (від інженерів або з минулого прогону)
скрипт не чіпає і навіть не витрачає на неї веб-пошук.

Кабельно-провідникова продукція (кабелі, короби, лотки, конектори) у прайсах **не шукається**
і одразу йде в інтернет: потрібних брендів там немає, і fuzzy-match на них помилявся.

## Автономність

Цей репозиторій ні від чого зовнішнього не залежить: власний код, власні секрети,
власний розклад. **У коді немає жодного id файлу чи папки** — усі посилання на Google
задаються ззовні, через секрети й змінні. Тому один і той самий код працює з будь-яким
Google-акаунтом: змінюються тільки значення в налаштуваннях репозиторію.

## Конфігурація

Усе зібрано у блоці **КОНФІГ** на початку `price_finder.py`. Кожне значення
перевизначається змінною оточення — у хмарі код правити не треба.

| Змінна | Обов'язково | Що це |
|--------|-------------|-------|
| `SHEET_URL` | **так** | посилання на робочу таблицю |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | **так** | ключ сервісного акаунта (весь JSON одним рядком) |
| `PRICE_FOLDER_ID` | рекомендовано | id папки з прайсами ETI/CHINT |
| `SERPER_API_KEY` | ні | ключ Serper; немає — інтернет-пошук вимкнено |
| `ETI_FILE_SEARCH` | ні | шматок назви файлу ETI (типово `eti_`) |
| `ETI_TAB_NAME` | ні | вкладка з цінами в ETI (типово `Price_`) |
| `ETI_DISCOUNT` | ні | знижка від ETI (типово `0.25`) |
| `CHINT_FILE_SEARCH` | ні | шматок назви файлу CHINT (типово `CHINT`) |
| `CHINT_TAB_NAME` | ні | вкладка з цінами в CHINT (типово `Прайс-Лист`) |
| `CHINT_DISCOUNT` | ні | додаткова знижка від CHINT (типово `0.0`) |

### Про `PRICE_FOLDER_ID`

id папки видно в її адресі: `drive.google.com/drive/folders/`**`<ЦЕ_ID>`**

- **задано** — прайси шукаються **тільки в цій папці**. Кладеш новий файл у папку —
  скрипт бере його. Передбачувано, рекомендований режим.
- **порожньо** — старий режим: пошук по всьому Диску за шматком назви, береться
  найсвіжіший за датою. Якщо однойменні файли є на кількох акаунтах — промахується.

## Дві кнопки запуску

Той самий код, два входи — під різних людей.

**GitHub Actions** — для власника репозиторію. Вкладка **Actions → Оновлення цін СЕС →
Run workflow**, плюс автоматичний запуск 1 і 15 числа о 01:00 UTC. Потребує доступу до репозиторію.

**Streamlit** — для колег без доступу до репозиторію. Публічне посилання, кнопка
«Оновити ціни», живий журнал виконання і відмітка останнього оновлення.
Розгортається на [share.streamlit.io](https://share.streamlit.io): вказати цей репозиторій,
головний файл `streamlit_app.py`, і продублювати секрети в **Settings → Secrets**
(формат TOML: `SHEET_URL = "..."`).

## Serper — вимкнено за замовчуванням

Без `SERPER_API_KEY` скрипт **не падає**: він повідомляє, що інтернет-пошук вимкнено,
і заповнює тільки те, що знайшлося у прайсах ETI та CHINT. Решта позицій лишається порожньою —
їх проставить інженер вручну.

Щоб увімкнути: зареєструватися на [serper.dev](https://serper.dev), взяти ключ і покласти
його в секрет `SERPER_API_KEY`. Вимкнути назад — видалити секрет. Код чіпати не треба
в жодному з напрямків.

## Налаштування з нуля

**1. Сервісний акаунт Google.** У Google Cloud Console на своєму акаунті:
створити проєкт → увімкнути **Google Sheets API** і **Google Drive API** →
IAM & Admin → Service Accounts → створити акаунт → Keys → Add key → JSON.
Завантажений файл **нікуди не комітити** — він піде в секрет.

**2. Дати сервісному акаунту доступ до файлів.** Це найчастіша причина «нічого не працює»:
сервісний акаунт — це окремий «користувач» зі своєю поштою виду
`щось@проєкт.iam.gserviceaccount.com`. Розшарити на неї:

- робочу таблицю — доступ **Редактор** (скрипт у неї пише);
- папку з прайсами — доступ **Переглядач** (достатньо читання).

**3. Секрети GitHub** (Settings → Secrets and variables → Actions → *Secrets*):
`GOOGLE_SERVICE_ACCOUNT_JSON` (увесь JSON), `SHEET_URL`. За бажанням `SERPER_API_KEY`.

**4. Змінні GitHub** (там само, вкладка *Variables*): `PRICE_FOLDER_ID`.

**5. Перевірка:** Actions → Run workflow. У журналі має бути видно назви обох прайсів
(`📋 ETI прайс: …`, `📋 CHINT прайс: …`) і кількість оброблених позицій.

## Чеклист: чи придатні файли

Перед першим запуском варто перевірити три речі — вони ламають роботу найчастіше.

**Робоча таблиця — нативна Google-таблиця, а не `.xlsx`.** Якщо в адресі файлу є
`rtpof=true`, або в Таблицях зверху біля назви написано `.XLSX` — це завантажений
Excel-файл. Google Sheets API у такі писати **не вміє**. Лікується так: відкрити файл →
**Файл → Зберегти як таблицю Google**. Утвориться новий файл з **новим id** — саме його
прописувати в `SHEET_URL`.

**Прайси ETI і CHINT — навпаки, мають лишатися `.xlsx`.** Скрипт качає їх як файли
і розбирає через `openpyxl`. Конвертувати їх у Google-таблиці **не треба**.

**Вкладки називаються так, як очікує конфіг.** У таблиці — `Довідник обладнання та цін`,
в ETI — назва містить `Price_`, у CHINT — `Прайс-Лист`. Інакше задати свої значення змінними.

## Заміна прайсу

1. Покласти новий файл у папку `Price_ETI_CHINT`. Вимоги: формат **`.xlsx`** (не конвертувати
   в Google-таблицю), у назві має лишитись `eti_` або `CHINT`, вкладка з цінами —
   `Price_…` для ETI і `Прайс-Лист` для CHINT.
2. Старий файл можна не видаляти: серед відповідних береться **найсвіжіший за датою зміни**.
   Але чистіше прибирати, щоб потім не гадати.
3. Доступ новому файлу видавати не треба — він успадковує його від папки.
4. Запустити: **Actions → Оновлення цін СЕС → Run workflow** (≈7 хв) або кнопкою у Streamlit.
5. Перевірити: у шапці вкладки «Довідник» оновиться відмітка «Останнє оновлення цін»,
   а в кінці логу буде зведення — скільки цін з ETI, скільки з CHINT, скільки лишено без змін.
